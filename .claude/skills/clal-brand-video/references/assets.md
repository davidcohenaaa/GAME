# נכסי מותג (assets/)

כל קובץ SVG חולץ וקטורית מספר המותג. הצבע הוא `currentColor`, כך שצובעים את הנכס עם `color` ב-CSS.

| קובץ | מה | מקור בספר (עמוד / אינדקס path) |
|---|---|---|
| `symbol.svg` | סמל ✕ לבד | עמ׳ 18 / 33–34 |
| `logo-line.svg` | "כלל ✕ ביטוח ופיננסים", שורה אחת. שני ה-paths האחרונים הם הסמל (לצבוע ב-`--symbol`) | עמ׳ 23 / 48–65 |
| `behave.svg` | לוגו מוצר "Clal Behave". ה-path האחרון הוא קו הבועית; הטקסט "ביטוח רכב" מתווסף ב-HTML | עמ׳ 36 / 139–149 |
| `carkey.svg` | מפתח רכב (ביטוח רכב) | עמ׳ 48 / 67 |
| `mug.svg` | ספל | עמ׳ 47 / 54 |
| `laptop.svg` | לפטופ | עמ׳ 47 / 105 |
| `plant.svg` | עציץ (קרן השתלמות) | עמ׳ 47 / 91 |
| `clock.svg` | שעון מעורר | עמ׳ 47 / 107 |
| `pillow.svg` | כרית (ביטוח דירה) | עמ׳ 47 / 57 |
| `bag.svg` | שקית קניות | עמ׳ 47 / 97 |

**בתבנית:**
- **נכס כללי:** מזריקים עם `<template id="mug"><!--ASSET:mug--></template>`, ואז `sil('mug', 'var(--digital)', x, y, width, extraCss)`.
- **לוגו המוצר:** משתמשים ב-`behave(width, color, {...})`, שממקם את טקסט הבועית לפי `BV`/`BP`.

**האינדקסים תלויים בגרסת pdftocairo.** לפני ייצוא לאמת עם `pdf_paths.js`, לפי מיקום וגודל.

## חילוץ נכס חדש מהספר
```bash
export NODE_PATH=$(npm root -g)
pdftocairo -svg -f 47 -l 47 book.pdf /tmp/p47.svg                    # עמוד אחד ל-SVG
node scripts/pdf_paths.js /tmp/p47.svg                               # רשימת paths: אינדקס, צבע, x/y/w/h
node scripts/pdf_export.js /tmp/p47.svg 60 assets/phone.svg          # ייצוא (אפשר טווחים: 139-149,151)
```
אחרי ייצוא: לבדוק תצוגה מקדימה, עם `<img>` על רקע קרם וצילום מסך עם Playwright, ולהוסיף שורה לטבלה למעלה.
