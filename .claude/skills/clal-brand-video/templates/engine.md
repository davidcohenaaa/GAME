# המנוע: איך כותבים סצנות

הדוגמה `example-behave-wfh.src.html` היא גם המנוע. מתחילים ממנה, משאירים את כל העזרים, ומחליפים רק את:
- `T`;
- רשימת `sc(...)`;
- `SH` (צורות הקו);
- `K` (מפתחות הקו);
- תבניות הנכסים (`<template>`).

## עקרון הזמן
- **כל הזמנים אבסולוטיים, בשניות מתחילת הסרטון.**
- `window.__setTime(t)`:
  - מציג רק את הסצנה ש-`s <= t < e` שלה.
  - מעמיד את כל אנימציות ה-CSS על הזמן `t`.
  - מריץ את פונקציות העדכון של הסצנה הפעילה.
  - מצייר את הקו הרציף.
- **לכן הכל דטרמיניסטי:** אסור להשתמש ב-`Date`, ב-`setTimeout` או ב-`requestAnimationFrame` לתזמון. `Math.random` מותר רק עם ערכים קבועים מראש.
- `T` הוא האורך הכולל. `window.__duration = T`.

## עזרים
| עזר | מה עושה |
|---|---|
| `sc(s, e, bg, s => html, (t, el, s) => {...})` | מוסיף סצנה מ-`s` עד `e` עם רקע `bg`. ה-HTML נבנה פעם אחת. פונקציית העדכון (אופציונלית) רצה בכל פריים שהסצנה פעילה בו. |
| `A(name, at, dur=.45, ease)` | מחרוזת `animation:` ל-CSS: אנימציה `name` שמתחילה ב-`at` (אבסולוטי). |
| `pill(txt, cls, style)` | בועית. `cls='f'` = מילוי (צבע ב-`style`: `background:...;color:...`); ריק = קו מתאר בצבע הטקסט. |
| `sil(id, color, x, y, w, extraCss)` | סילואטה מתוך `<template id>`, ממוקמת בפיקסלים. |
| `behave(w, color, {pillFill, pillText, hidePill, id})` | לוגו Clal Behave עם בועית. |
| `chars(txt, at, step, anim)` | אנימציה לכל אות בנפרד (למשל `glow`, חשיפה אות-אות). |
| `spans(txt, cls)` | עוטף כל אות ב-span, כדי שפונקציית עדכון תזיז אותיות (נפילה, עפיפה). |
| `tpl(id)` | ה-SVG הגולמי של נכס. |
| `clamp`, `lerp`, `ease`, `easeIO` | עזרי חישוב לפונקציות עדכון. |

- **מחלקות CSS:**
  - `.w`: שורת טקסט ממורכזת במיקום אבסולוטי (`top` בפיקסלים).
  - `.x` / `.l` / `.r` / `.m` / `.s`: משקלי Polin.
  - `.gap`: רווח בין בועיות.
  - `.half`: חצי מסך (למסך מפוצל).
  - `.icon`: אייקון קו; `stroke-width` ב-style.
- **אנימציות קיימות:**
  - כניסה: `in`, `up`, `pop`, `fromR`, `dropIn` (עם `--r`).
  - הגדלה איטית: `push`.
  - סילואטות: `silIn` (עם `--r0` ו-`--r1`).
  - מסך מפוצל: `slideUp`, `slideDown`.
  - חשיפה: `wipe` (מימין), `glow` (אות-אות).
  - ציור קו: `drawP` (ל-path עם `pathLength="1" stroke-dasharray="1 1"`).

## הקו הרציף
- **צורות (`SH`):** כל צורה היא פוליליין של `N` נקודות, דגום לפי אורך. עזרים:
  - `line(x1, x2, y)`: קו אופקי.
  - `rrect(x1, y1, x2, y2, r)`: מלבן מעוגל. כש-`r` = חצי הגובה מתקבלת בועית.
  - `fillet(points, r)`: פוליליין עם פינות מעוגלות (רק כש-`ROUND`).
  - `gaugeArc()`: קשת הספידומטר.
- **מפתחות (`K`):** כל שורה היא `[time, shapeName, color, opacity, drawn]`.
  - בין שתי שורות עוקבות הקו עושה מורפינג בהאטה.
  - שתי שורות עם אותה צורה יוצרות החזקה.
  - `drawn` (0–1) קובע כמה מהקו מצויר, וכך מקבלים ציור הדרגתי בהתחלה.
  - **החלפת צבע ברגע החיתוך:** מוסיפים שורה 0.05 שנ׳ אחרי חיתוך הרקע, עם אותה צורה וצבע חדש. ראו `[3.0 ...]` ו-`[3.05 ...]` בדוגמה.
- **צורה שתלויה ב-DOM** (למשל הבועית סביב הלוגו): מחשבים אותה במדידה חד-פעמית אחרי בניית הסצנות. ראו `measurePill`.

## פורמטים אחרים
- **הגודל קבוע ב-CSS:** `html, body` ו-`#stage` הם 1080×1920, וכך גם `viewBox` של `#lineLayer`.
- **ל-1:1 או 16:9:** לשנות את שלושתם, את מיקומי ה-`top`, `left` ו-`SH`, ולרנדר עם `W`/`H` מתאימים.

## מנוע ההסבר (16:9, `explainer-16x9.src.html`)
אותם עזרים (`sc`, `A`, `pill`, הקו הרציף), עם התוספות האלה:

| עזר | מה עושה |
|---|---|
| `CUES`, `C(sec, i)` | תזמוני הקריינות מ-`cues.json`, מוזרקים בבנייה (`build.py --cues`). `T = CUES.duration`. |
| `hd(s, e, l1, l2, color, {sub, id, top, size})` | כותרת מימין: שורה דקה (Light) + שורה מודגשת (Semibold) + שורת משנה רשות. שכבה שקופה מעל הסצנה. |
| `ic(id, color, cx, cy, size, css)` | אייקון ממורכז ב-(cx,cy). |
| `blob(color, cx, cy, rx, ry, css)` | כתם: אליפסה שטוחה בצבע אחד, מתחת לאייקון. |
| `lbl(txt, cx, y, color, css, size)` | תווית ממורכזת (למשל מתחת לצומת). |
| `OUT(at, dur, name)` | אנימציית יציאה עם `forwards` בלבד, כדי שלא תדרוס את הכניסה. |
| `lineState(t)`, `lineHead(t)` | מצב הקו בזמן `t`, וראש הקו המצויר. לאובייקט "שנוסע" על הקו (ראו סצנה 8). |

- **שכבות:** רקעים ← הקו הרציף ← תוכן הסצנות ← כתוביות ולוגו פינתי. הקו עובר מאחורי כתמים ואייקונים, ולכן אפשר לחבר בו בין אובייקטים בלי לחשב קצוות.
- **מעברים:** הרקע של כל סצנה נחשף באליפסה שגדלה מנקודה (`{ox, oy}` באופציות של `sc`), ונשאר מתחת לסצנה הבאה עד סוף החשיפה. התוכן נעלם לבד ב-0.25 שנ׳ האחרונות. `noReveal` לסצנה הראשונה.
- **`bgHtml`:** תוכן ששייך לרקע ולכן מתחת לקו, למשל חצי מסך במסך מפוצל, או נתיבים שהקו נוסע עליהם.
- **צורות דינמיות:** ערך ב-`SH` יכול להיות פונקציה של `t` (למשל `wave`, גל שזז).
- **ציור ענפים:** פוליליין שחוזר לשורש בין ענף לענף (`branch`). כמה מצויר בכל צומת מחושב מהאורך המצטבר (`BR`).
- **כתוביות:** `captions(t)` מציגה את הביטוי הפעיל. מיקום וצבע לפי הסצנה; במסך מפוצל מתחת לחצי הרלוונטי.
- **מדידות:** קו תחתון לפי רוחב טקסט אמיתי נמדד בקריאה הראשונה ל-`__setTime` (אחרי שהפונטים נטענו), בלי האנימציות.
