# סרטוני מותג – כלל ביטוח ופיננסים

הסקיל מפיק סרטון MP4 מקופי, לפי ספר המותג של כלל. הסרטון נבנה כעמוד HTML עם אנימציה דטרמיניסטית (`window.__setTime(t)`), מרונדר פריים-פריים עם Playwright ומקודד עם ffmpeg.

**לפני כל עבודה לקרוא:**
- `references/brand-notes.md`: כללי המותג. חובה.
- `templates/engine.md`: העזרים במנוע ואיך כותבים סצנה.
- `references/assets.md`: רק כשצריך סילואטה או לוגו שלא ברשימה.

שתי דוגמאות מלאות ועובדות:
- `templates/example-behave-wfh.src.html`: מודעה קינטית, Clal Behave לעובדים מהבית, 26 שניות, 9:16, מוזיקה בלבד.
- `templates/explainer-16x9.src.html`: סרטון הסבר "קופת גמל להשקעה", 90 שניות, 16:9, עם קריינות, כתוביות ואייקונים. לסרטון הסבר עובדים לפי הסעיף "סרטון הסבר עם קריינות" למטה.

## תהליך עבודה

1. **איסוף קלט.** לוודא שיש:
   - הקופי המלא, כולל כתב קטן ודיסקליימר מאושר. אם אין דיסקליימר, להציע נוסח ולסמן שצריך אישור משפטי.
   - פורמט: ברירת מחדל 9:16 (1080×1920). 1:1 = 1080×1080, 16:9 = 1920×1080.
   - מוצר ולוגו: Clal Behave או אחר.
   - **PDF של ספר המותג**, לחילוץ פונטי Polin. אם אין, לבקש מהמשתמש להעלות אותו. בלעדיו הטקסט יוצג בגופן הגיבוי.
2. **בדיקת סביבה:** `bash scripts/check_env.sh`. להתקין מה שחסר לפי מה שהסקריפט מדפיס.
3. **תיקיית עבודה:** `bash scripts/new_project.sh <dir> <brand_book.pdf>`. הסקריפט מעתיק את התבנית ל-`<dir>/video.src.html`, את גופן הגיבוי, ומחלץ את Polin ל-`<dir>/brand-fonts/`.
   - **הפונטים מחולצים לתרגיל/המחשה בלבד.** אסור להעלות אותם ל-Git; ה-`.gitignore` בתיקייה כבר מטפל בזה. לפרסום אמיתי צריך קבצים מורשים.
4. **סטוריבורד** (לכתוב טבלה קצרה לפני הקוד):
   - **קצב:** פעימה = 0.5 שנ׳ (120BPM). מילה או שתיים לפעימה. 3–6 פעימות לסצנה. סרטון של 20–30 שנ׳.
   - **צבעים:** לכל סצנה רקע וצבע אלמנט מתוך **טבלת הצירופים המותרים** ב-brand-notes. לגוון בין סצנות סמוכות.
   - **רעיון חזותי לכל מסר.** לחזור לרעיונות שעבדו:
     - אובייקט שעובר דרך מילה.
     - מילה בתוך צורה (בית, משבצת חניה).
     - שורות של בועיות שמתרבות.
     - אותיות שנופלות ומתחלפות.
     - ספידומטר שיורד ב-X%.
     - מסך מפוצל.
   - **הקו הרציף:** לתכנן מה הוא הופך להיות בכל סצנה (קו תחתון, כביש, מסגרת, קשת, קו חיתוך, בועית סביב הלוגו).
   - **סיום:** תמיד לוגו מוצר + סלוגן + לוגו "כלל ביטוח ופיננסים" + דיסקליימר.
5. **כתיבת הסצנות** ב-`<dir>/video.src.html`: לשנות את `T`, את רשימת `sc(...)`, את המפתחות `K` ואת הצורות `SH`, לפי `templates/engine.md`. נכסים מוזרקים עם `<template id="x"><!--ASSET:x--></template>`.
6. **פריימי בדיקה לפני רינדור מלא** (חוסך זמן):
   ```bash
   export NODE_PATH=$(npm root -g)
   python3 scripts/build.py <dir>/video.src.html <dir>/video.html
   node scripts/render.js "<dir>/video.html?<query>" <dir>/frames-test 1.2,3.4,5.9,...   # פריים מכל סצנה + מעברים
   bash scripts/contact_sheet.sh <dir>/frames-test <dir>/test-sheet.png 8
   ```
   לפתוח את גיליון המגע ולבדוק לפי הצ'קליסט למטה. לתקן ולחזור.
7. **רינדור מלא:** `bash scripts/make_video.sh <dir> "<query>" <out.mp4>`. הסקריפט מריץ build, מרנדר את כל הפריימים, מייצר מוזיקה (`scripts/music.py`, התופים נעצרים בסצנת הלוגו), מקודד ל-MP4 ויוצר גיליון מגע. לפתוח את הגיליון ולבדוק שוב.
8. **מסירה:** לשלוח את ה-MP4 ולפרט:
   - מה נעשה, סצנה אחר סצנה.
   - חריגות מספר המותג, אם היו.
   - מה צריך אישור: דיסקליימר, נתונים, סילואטה חדשה.

## סרטון הסבר עם קריינות (16:9)
כשיש תסריט קריינות (הסבר מוצר, "כל מה שחשוב לדעת"):
1. **קריינות:** לכל חלק בתסריט קובץ אודיו (למשל ElevenLabs) וקובץ טקסט עם ביטוי אחד בכל שורה, לפי ההפסקות בדיבור. לפני יצירת קריינות בשירות בתשלום, להציג למשתמש את העלות ולקבל אישור.
2. **תזמונים:**
   ```bash
   python3 scripts/vo_cues.py --out-wav <dir>/vo.wav --out-json <dir>/cues.json --tempo 1.05 \
       <dir>/vo/s1.mp3:<dir>/vo/s1.txt <dir>/vo/s2.mp3:<dir>/vo/s2.txt ...
   ```
   הסקריפט מזהה הפסקות, מחבר את החלקים ומפיק זמן התחלה לכל ביטוי. אם מודפסת אזהרה על מספר הפסקות, לבדוק את החלוקה לשורות. `--tempo` עד כ-1.08 עדיין נשמע טבעי (לקיצור לאורך היעד).
3. **תיקייה:** `TEMPLATE=explainer bash scripts/new_project.sh <dir> <book.pdf>`.
4. **סצנות לפי ה-cues:** בעמוד `C(sec, i)` מחזיר את זמן תחילת הביטוי, וכל ביט חזותי נצמד אליו. מילה בתוך משפט: זמן הביטוי + חלק יחסי לפי מספר התווים. פרטים ב-`templates/engine.md`, בסעיף "מנוע ההסבר".
5. **בדיקה ורינדור:** כמו בשלבים 6–7, עם `W=1920 H=1080` ו-`TILE_W=400` לגיליון המגע. `make_video.sh` מזהה את `cues.json` ו-`vo.wav`, מרנדר במקביל, יוצר מוזיקה רכה (`music.py ... soft`) ומנמיך אותה מתחת לדיבור (`mix_audio.sh`).

**כללים לסרטון הסבר:**
- כותרת קצרה (שורה דקה + שורה מודגשת) לכל משפט. לא להעתיק את הקריינות לכותרת; הכתוביות כבר עושות את זה.
- כתוביות בתחתית לכל אורך הסרטון, חוץ מהלוגו בסיום. במסך מפוצל הכתובית עוברת לחצי שעליו מדברים.
- אייקונים רשמיים (`assets/icons/`) על כתמים אליפטיים בצבעים מהצירופים המותרים. אייקון שצויר (`assets/icons/drawn/`) לסמן לאישור מותג.
- אם התוכן רגולטורי (פיננסים, ביטוח): בלי מספרים, אחוזים וגרפים בוויזואל, אלא אם אושרו. גילוי נאות רק בנוסח מאושר; עד שמגיע – מקום שמור מסומן בסיום.
- רפרנס של מתחרה: לוקחים מבנה וקצב, לא קומפוזיציות, אובייקטים או צבעים.

## סביבה בלי רינדור וידאו (למשל שיחה ב-claude.ai)
אם `check_env.sh` מראה ש-Chromium/Playwright או ffmpeg חסרים, מנסים להתקין:
```bash
npm i -g playwright && npx playwright install chromium
```
אם ההתקנה נכשלת (בדרך כלל אין גישת רשת), לא מוותרים. מוסרים **קובץ HTML מתנגן** במקום MP4:
1. שלבים 1–5 כרגיל. חילוץ הפונטים דורש רק Python עם pikepdf ו-fonttools.
2. בונים קובץ יחיד עם הפונטים בפנים:
   ```bash
   python3 scripts/build.py <dir>/video.src.html <dir>/video-standalone.html --inline-fonts
   ```
3. מוסרים את `video-standalone.html` כקובץ להורדה (או כ-artifact, אם אפשר). בדפדפן רגיל האנימציה מתנגנת בלולאה במלוא האיכות. לבחירת אופציה מוסיפים לכתובת למשל `?car=key&style=round`.
4. מסבירים למשתמש: את ה-HTML אפשר להקליט מסך, ול-MP4 מלא עם מוזיקה מריצים את אותו סקיל ב-Claude Code.

בלי דפדפן אי אפשר לבדוק פריימים. לכן בודקים את הקוד בקפידה מול הצ'קליסט, ומשאירים מיקומים שכבר עבדו בדוגמה ככל האפשר.

## צ'קליסט בדיקה (בכל גיליון מגע)
- **צבעים:** רק צבעי הפלטה, וכל רקע/אלמנט מתוך צירוף מותר. אין לבן (רק קרם `#FBF2EB`), אין שחור טהור (רק `#262B3A`) ואין גרדיאנטים.
- **טקסט:**
  - Polin. משקל דק לכותרות, הדגשה ב-Medium/Semibold. לא Bold כבד לכל הטקסט.
  - טקסט בצבע כחול-שחור או קרם, עם קונטרסט טוב.
  - אין טקסט שגולש מהמסך או נחתך. במילה ארוכה להקטין גודל.
- **בועיות:** מילוי **או** קו מתאר, לעולם לא שניהם. סימן פיסוק או חץ בבועית נפרדת.
- **סילואטות ואייקונים:**
  - סילואטות שטוחות בצבע אחד, בלי פרטים ובלי קו. מתוך הספר עדיף, או בסגנון גזור-ידני.
  - אייקונים: קו בלבד, צבע אחד.
- **הקו הרציף:** לא חוצה טקסט, ומתחלף צבע בחיתוך הרקע.
- **לוגואים:**
  - הלוגו מהקבצים, לא כטקסט, ולא מעוות.
  - "כלל ביטוח ופיננסים" ברוחב 200px לפחות, מיושר לימין.
  - טקסט הלוגו קרם או כחול-שחור, והסמל בכחול.
- **תחילת הסרטון:** הפריים הראשון לא ריק (חשוב לתמונה הממוזערת).
- **דיסקליימר:** קריא, וכוכבית בכל נתון מספרי.

## אופציות שכבר קיימות בדוגמה
- `?car=key`: מפתח רכב (ברירת מחדל). `?car=car`: סילואטת רכב.
- `?style=round`: פינות מעוגלות, אליפסות במקום עיגולים, ושקית קניות בסצנת התשלום.

אפשר להוסיף אופציות באותה שיטה (`Q.get(...)`), כדי לרנדר כמה גרסאות מאותו מקור.

## תקלות נפוצות
- **תו מופיע בגופן אחר:** תת-הגופן שחולץ מהספר מכיל רק תווים שהופיעו בספר (למשל "?" ו-₪ חסרים, ובמשקל Light חסרות אותיות סופיות). זה תקין; הגיבוי הוא Polin Regular ואחריו Heebo. לפרסום צריך קבצים מורשים.
- **`missing file` בזמן רינדור:** חסרה תיקיית `fonts/` או `brand-fonts/` ליד ה-HTML. להריץ `new_project.sh`.
- **אובייקט "מרחף" מעל הקו:** למדוד את קו המתאר האמיתי (`getPointAtLength`), לא את `getBoundingClientRect` של אלמנט מסובב. ראו `el._ext` בסצנת הנסיעה בדוגמה.
- **רינדור איטי:** כ-0.3 שנ׳ לפריים לתהליך. `make_video.sh` מחלק את הפריימים בין כמה תהליכים (`JOBS`, וגם `FROM`/`TO` ב-`render.js`). 90 שנ׳ ב-16:9 עם 4 תהליכים: כ-5 דקות. להשתמש בפריימי בדיקה עד שהכל מוכן.
- **הכתוביות לא מסונכרנות:** לבדוק את `cues.json`. אם `vo_cues.py` הזהיר על מספר הפסקות, לפצל או לאחד שורות בקובץ הטקסט כך שכל שורה תסתיים בהפסקה אמיתית.
