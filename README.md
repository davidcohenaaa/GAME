# אתר תיאוריה לרכב פרטי

אתר סטטי: HTML, CSS ו-JavaScript רגיל, בלי build. כל התוכן יושב בתיקיית `content/` ואפשר לערוך אותו בלי לגעת בקוד.

## הרצה מקומית
הדפים טוענים קבצי JSON, ולכן צריך שרת (פתיחה ישירה של הקובץ לא תעבוד):

```
python3 -m http.server 8000
```
ואז לפתוח `http://localhost:8000`.

## איך עורכים

| רוצים לשנות | עורכים |
|---|---|
| שאלה חדשה או קיימת | `content/questions.json` |
| תמרור (נוצר אוטומטית, ראו להלן) | `content/signs.json` |
| חומר לימוד של נושא | `content/topics/<id>.md` |
| רשימת הנושאים | `content/topics.json` |
| שם האתר, מספר שאלות במבחן, זמן, מספר טעויות מותר | `content/site.json` |
| צבעים | משתני `:root` בראש `css/styles.css` |

### מבנה שאלה
```json
{
  "id": "q007",
  "topic": "rules",
  "question": "טקסט השאלה?",
  "answers": ["תשובה א", "תשובה ב", "תשובה ג", "תשובה ד"],
  "correct": 1,
  "explanation": "הסבר קצר שמופיע אחרי המענה."
}
```
- `correct` הוא המיקום של התשובה הנכונה, מתחיל ב-0 (0 = הראשונה).
- ה-`id` חייב להיות ייחודי, והוא מזהה את השאלה בהתקדמות השמורה.
- תמונה אופציונלית: `"image": "images/q007.png"` ו-`"imageAlt": "תיאור התמונה"`.

## אחוז המוכנות
בדף הראשי מוצג "כמה אתה קרוב לידע". שאלה נחשבת **בשליטה** אם ענית עליה נכון לפחות פעמיים והתשובה האחרונה נכונה. האחוז הוא שאלות בשליטה חלקי כלל השאלות באתר, ולכן הוא יורד אם טועים שוב, ומשקף ידע ולא רק ניסיון. נושא נחשב "הושלם" ב-80% שליטה (`TOPIC_GOAL` ב-`js/home.js`). ההתקדמות נשמרת בדפדפן בלבד.

## המשחק
`game.html`: מרוץ של 60 שניות עם 3 חיים ובונוס רצף, במצב "מה פירוש התמרור?" ובמצב שאלות. התשובות במשחק נספרות גם בהתקדמות.

## לוח התמרורים
`content/signs.json` ו-`images/signs/` נוצרו אוטומטית מלוח התמרורים הרשמי של משרד התחבורה (PDF, ספטמבר 2022): 393 תמרורים בעשרה חלקים, כל אחד עם מספר רשמי, תמונה, פירוש ותוקף.

כדי לייצר אותם מחדש (למשל כשמתפרסם עדכון):
```
pip install pymupdf
python3 scripts/extract_signs.py <נתיב-ל-PDF>
```
הסקריפט כותב מחדש את `content/signs.json` ואת התמונות. אפשר גם לערוך ידנית פירוש או כותרת ב-`signs.json`, אבל עריכה ידנית תידרס בהרצה חוזרת של הסקריפט.

כל תמרור: `number` (המספר הרשמי), `part` ו-`category` (חלק בלוח), `meaning` (פירוש), `validity` ("כוחו יפה"), `images` (תמונה אחת או יותר).

## בדיקת תקינות לפני פרסום
```
node scripts/validate.mjs
```
הסקריפט מוודא שלכל שאלה יש נושא קיים, תשובה נכונה תקינה ו-id ייחודי, ושקבצי התמונות קיימים.

## פרסום
GitHub Pages: Settings, ואז Pages, ואז לבחור את הענף הראשי ואת התיקייה הראשית.

## חשוב
התמרורים לקוחים מהלוח הרשמי. שאלות התרגול הן עדיין 6 שאלות טיוטה לדוגמה, ולפני פרסום יש להחליף אותן במאגר השאלות הרשמי של משרד התחבורה.
