# GEO Tracker — כלל מול המתחרים בתשובות מנועי בינה

הכלי שואל את מנועי הבינה (ChatGPT, Gemini, Claude, Perplexity, ואופציונלית Grok ו-DeepSeek) את רשימת הפרומפטים שלכם, ובודק בכל תשובה:

- **אילו חברות ביטוח מוזכרות**, באיזה סדר, ובאיזה טון.
- **אילו מקורות המנוע ציטט**: אתר כלל, אתרי מתחרים, או אתרי צד ג' (השוואות, כתבות).
- **למה המנוע ממליץ על המתחרה**: מחיר, שירות, תביעות, אפליקציה, מוסכי הסדר, גרירה וכו'. ומה מזה לא נאמר על כלל.

ואז הוא מחזיר **רשימת פעולות לפי עדיפות** לכל פרומפט שבו כלל בפער: איזה עמוד לבנות או לשפר, באילו אתרים צריך להופיע, אילו עמודי מתחרים המנועים מצטטים, ומה יש בעמודים האלה שחסר אצלכם (בדיקת עמודים).

## התקנה והפעלה

צריך Node.js בגרסה 20.12 ומעלה. אין תלויות להתקנה.

```bash
cd geo-tracker
cp .env.example .env      # ממלאים מפתחות API
npm start                 # http://localhost:8787
```

לניסיון בלי מפתחות: `npm run mock`. זה מריץ מנועים מדומים כדי לראות את הדשבורד.

## מפתחות API

כל מנוע שיש לו מפתח בקובץ `.env` מופעל אוטומטית. אין צורך בכולם.

| מנוע | משתנה | איפה מוציאים מפתח | חיפוש ברשת + מקורות |
|---|---|---|---|
| ChatGPT | `OPENAI_API_KEY` | platform.openai.com | כן |
| Gemini | `GEMINI_API_KEY` | aistudio.google.com | כן (Google Search) |
| Claude | `ANTHROPIC_API_KEY` | console.anthropic.com | כן |
| Perplexity | `PERPLEXITY_API_KEY` | perplexity.ai/settings/api | כן |
| Grok | `XAI_API_KEY` | console.x.ai | לא, עונה מהידע של המודל |
| DeepSeek | `DEEPSEEK_API_KEY` | platform.deepseek.com | לא, עונה מהידע של המודל |

המפתחות נשמרים רק בשרת ולא נשלחים לדפדפן. הקובץ `.env` לא נכנס ל-git.

אם יש מפתח של Anthropic, בלשונית "מה לעשות" מופיע כפתור **"תוכנית פעולה מלאה עם Claude"**, שכותב תוכנית ל-90 יום מתוך הנתונים.

## איך משתמשים

1. **הגדרות**: בודקים את רשימת הפרומפטים (אפשר לערוך) וממלאים לכל נושא את כתובת העמוד של כלל שאמור לענות עליו.
2. **הרצה חדשה**: בוחרים מנועים ומספר חזרות. ברירת המחדל היא 3 חזרות, כי מנועים עונים אחרת בכל פעם. לפני ההרצה רואים כמה קריאות API היא תבצע.
3. **סקירה**: אחוז האזכורים (Share of Voice) של כל חברה, כלל מול הפניקס בכל מנוע, והנימוקים שהמנועים נותנים להפניקס ולא לכלל.
4. **מה לעשות**: הפרומפטים בפער לפי עדיפות. לכל אחד מופיעות פעולות קונקרטיות, ציטוטים מהתשובות, וכפתור **"בדיקת עמודים מול המתחרים"**. הבדיקה משווה את העמוד שלכם לעמודי המתחרים שהמנועים ציטטו (מחירים מפורשים, טבלאות, Schema מסוג FAQPage, תאריך עדכון, תשובה ישירה בראש העמוד, עומק התוכן) ומפרטת מה חסר אצלכם.
5. **מטריצת פערים**: כל פרומפט מול כל מנוע. לחיצה על פרומפט פותחת את התשובות המלאות עם האזכורים המסומנים.
6. **מקורות**: האתרים שהמנועים מצטטים. העמודה "כשהמתחרה מוזכר וכלל לא" מראה את האתרים שמזינים את המתחרים, ושם כדאי להופיע.
7. **מגמה**: כיסוי לאורך זמן. כדאי להריץ שוב אחרי כל שינוי באתר.

## הרצה מהטרמינל ושיתוף דוח

```bash
# רק Claude, חזרה אחת לכל פרומפט
npm run run-once -- --engines claude --reps 1 "Claude – הרצה ראשונה"
# אפשר גם לבחור פרומפטים: --prompts p01,p05

# ייצוא ההרצה האחרונה לקובץ HTML אחד, עם כל התשובות
npm run export -- latest
```

הקובץ שנוצר (`data/report-<runId>.html`) עובד בלי שרת: אפשר לפתוח אותו, לשלוח אותו או לפרסם אותו כלינק. בדוח המשותף אין כפתורי הרצה, הגדרות ובדיקת עמודים.

## הרצה אוטומטית

- `SCHEDULE_HOURS=168` ב-`.env` מריץ פעם בשבוע כל עוד השרת פועל.
- או מ-cron של המערכת: `npm run run-once` (עם אותם פרמטרים כמו למעלה).

## פריסה בשרת

מגדירים `HOST=0.0.0.0` ו-`ACCESS_TOKEN=<סיסמה ארוכה>`, ונכנסים עם `http://server:8787/?token=<הסיסמה>`. ההרצות נשמרות כקבצי JSON בתיקייה `data/`.

## חשוב לדעת

- **API הוא לא בדיוק הצ'אט.** התשובות ב-API קרובות למה שמשתמש רואה, אבל לא זהות: באפליקציות יש התאמה אישית, היסטוריה וגרסאות מודל אחרות. לכן מסתכלים על אחוזים ממספר חזרות ועל המגמה, ולא על תשובה בודדת.
- **עלות.** הרצה מלאה היא 19 פרומפטים × מספר המנועים × 3 חזרות, כלומר כ-230 קריאות עם 4 מנועים. קריאות עם חיפוש ברשת עולות יותר מקריאה רגילה, ולכן כדאי לבדוק את המחירון של כל ספק.
- **זיהוי שמות.** הכלי מזהה גם צורות עם תחיליות ("בהפניקס", "לביטוח ישיר") ומתעלם מניקוד. מילים דו-משמעיות כמו "כלל" ("ככלל", "כלל החברות"), "מגדל" ו"הכשרה" נספרות רק בהקשר של חברת ביטוח. את רשימת החברות והכינויים עורכים ב-`config/brands.json`.
- **ניתוח נימוקים** ("למה ממליצים על המתחרה") מבוסס על מילות מפתח. הוא מכוון את העבודה, אבל כדאי לקרוא את הציטוטים עצמם.
