# GEO — ניתוח נראות מותג בתשובות AI

אפליקציית SaaS בעברית וב-RTL לבדיקה איך מותג מופיע בתשובות של מנועי AI:
Google AI Overview, Gemini, ChatGPT, Claude.

הנתונים נאספים בפועל מהמקורות, נשמרים במסד הנתונים, ומציגים היסטוריה לאורך זמן.

## מה יש כאן

| מסך | מה מציג |
| --- | --- |
| לוח בקרה | מדדי מפתח, חלוקה לפי תחומים, גרף מיקום לאורך זמן |
| נושאים ושאלות | ניהול נושאים ושאלות, אחוז הופעה ומיקום ממוצע |
| תשובות | תשובה מסוכמת מכמה מקורות AI, דירוג מותגים, לינקים, סינון לפי מקור |
| השוואות לפי תחום | דירוג משוקלל מול מתחרים + "למה הוא לפניי?" עם פעולות לשיפור |
| צור תוכן מהאתר שלי | הצעת תוכן שנבנית רק מהמידע באתר שלך |
| מתחרים / הגדרות | ניהול מותגים, הפעלת מקורות, סריקה ידנית ויומית |

## דרישות

- Node.js 20+ ו-bun (או npm)
- גישה למסד נתונים של Lovable Cloud (החיבור מוגדר בקובץ `.env`)

## התקנה והרצה

```sh
bun install     # או: npm install
bun run dev     # או: npm run dev
```

האתר נפתח ב-`http://localhost:8080`.

## איסוף נתונים

- **סריקה ידנית** — כפתור "סריקה ידנית" במסך ההגדרות.
- **סריקה אוטומטית** — פעם ביום, מופעל מההגדרות. קובץ ה-cron מוגדר במסד הנתונים
  ופונה ל-`/api/public/collect` עם כותרת `x-cron-secret`.
- מקורות נסרקים רק אם מופעלים בהגדרות. מקור שדורש מפתח חיצוני יוצג כ"ממתין למפתח API".

## משתני סביבה

| שם | מי קורא | הערה |
| --- | --- | --- |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`, `VITE_SUPABASE_PROJECT_ID` | דפדפן | מוגדרים ב-`.env` |
| `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `SUPABASE_PROJECT_ID` | שרת | מוגדרים ב-`.env` |
| `SERPAPI_API_KEY` | שרת | נחוץ רק ל-Google AI Overview |
| `COLLECT_CRON_SECRET` | שרת | סוד הסריקה היומית |

## מבנה

```
src/
  routes/        מסכים + מסלול ה-cron (api/public/collect.ts)
  lib/           אוסף הנתונים, חיבורי AI, פונקציות שרת
  components/    מעטפת האפליקציה ורכיבי ממשק
  integrations/  חיבור למסד הנתונים (נוצר אוטומטית)
supabase/
  migrations/    סכמת הנתונים, הרשאות, והנתונים הראשוניים
```

## הערות

- קבצים ב-`src/integrations/supabase/` ו-`src/routeTree.gen.ts` נוצרים אוטומטית — לא לערוך ידנית.
- אין עדיין חיבור ל-Perplexity.
- מסד הנתונים כולל מדיניות הרשאות (RLS): ללא התחברות אין גישה לנתונים.
