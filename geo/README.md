# GEO — ניתוח נראות מותג בתשובות AI

אפליקציה בעברית וב-RTL שבודקת איך **כלל ביטוח** מופיעה, מול המתחרים, בתשובות של מנועי AI:
ChatGPT, Gemini, Claude ו-Google AI Overview.

כל שאלה נשלחת לכל מנוע כמו שמשתמש בישראל היה שואל אותה (בעברית, עם חיפוש ברשת),
והתשובה האמיתית נשמרת. המותגים מזוהים בקוד מתוך טקסט התשובה – לפי סדר ההופעה הראשונה,
כולל שמות חלופיים (`brands.aliases`) – והקישורים לאתרים נבדקים מול המקורות שהמנוע ציטט.

## מה יש כאן

| מסך | מה מציג |
| --- | --- |
| לוח בקרה | מדדי מפתח, חלוקה לפי תחומים, גרף מיקום לאורך זמן |
| נושאים ושאלות | ניהול נושאים ושאלות, אחוז הופעה ומיקום ממוצע |
| תשובות | תשובה מסוכמת מכמה מקורות AI, דירוג מותגים, לינקים, סינון לפי מקור |
| השוואות לפי תחום | דירוג מול מתחרים + "למה הוא לפניי?" – השאלות שבהן המתחרה מקדים אותך |
| מתחרים | מדדי נראות לכל מותג ושמות מזוהים |
| צור תוכן מהאתר שלי | **עדיין דוגמה קבועה** – לא מחובר |
| הגדרות | הפעלת מקורות, סריקה ידנית ויומית |

## תחומים

רכב, דירה, בריאות, חיים, נסיעות לחו״ל, פנסיה וחיסכון, שירות ותביעות.
הרשימה ב-`src/lib/catalog.ts`; המותגים, הנושאים ו-21 שאלות הבדיקה נטענים ב-migration
`supabase/migrations/20261011090000_clal_catalog.sql`.

## דרישות

- Node.js 20+
- פרויקט Supabase עם ה-migrations מ-`supabase/migrations`
- קובץ `.env` לפי `.env.example`

## התקנה והרצה

```sh
npm install
npm run dev
```

האתר נפתח ב-`http://localhost:8080`.

## איסוף נתונים

- **סריקה ידנית** — כפתור "סריקה ידנית" במסך ההגדרות.
- **סריקה אוטומטית** — פעם ביום, מופעל מההגדרות. קובץ ה-cron מוגדר במסד הנתונים
  ופונה ל-`/api/public/collect` עם כותרת `x-cron-secret`.
- מקורות נסרקים רק אם מופעלים בהגדרות ויש להם מפתח. מקור בלי מפתח יוצג כ"ממתין למפתח API".

## משתני סביבה

כל המשתנים מתוארים ב-`.env.example`:

| שם | הערה |
| --- | --- |
| `VITE_SUPABASE_*`, `SUPABASE_*` | חיבור למסד הנתונים; `SUPABASE_SERVICE_ROLE_KEY` לשרת בלבד |
| `OPENAI_API_KEY` | ChatGPT |
| `GEMINI_API_KEY` | Gemini |
| `ANTHROPIC_API_KEY` | Claude (חיפוש ברשת צריך להיות מופעל בהגדרות הארגון ב-Console) |
| `SERPAPI_API_KEY` | Google AI Overview |
| `OPENAI_MODEL`, `GEMINI_MODEL`, `CLAUDE_MODEL` | אופציונלי – החלפת מודל |
| `APP_URL`, `COLLECT_CRON_SECRET` | הסריקה היומית |

## מבנה

```
src/
  routes/        מסכים + מסלול ה-cron (api/public/collect.ts)
  lib/           אוסף הנתונים, חיבורי AI, פונקציות שרת
  components/    מעטפת האפליקציה ורכיבי ממשק
  integrations/  חיבור למסד הנתונים (נוצר אוטומטית)
supabase/
  migrations/    סכמת הנתונים, הרשאות, והנתונים הראשוניים
```

## הערות

- קבצים ב-`src/integrations/supabase/` ו-`src/routeTree.gen.ts` נוצרים אוטומטית — לא לערוך ידנית.
- אין עדיין חיבור ל-Perplexity.
- אין עדיין התחברות: כל מי שמגיע לאתר יכול לצפות, לשנות הגדרות ולהפעיל סריקה. לא לפרסם לפני שמוסיפים.
- כל סריקה דורסת את התשובה הקודמת לכל שאלה ומקור; ההיסטוריה נשמרת רק כמדדים יומיים (`snapshots`).
